# Cybersecurity Awareness Chatbot GUI 
 
Part 2 of PROG6221 Portfolio of Evidence 
 
## How to Run 
1. Open CybersecurityChatbotGUI.sln in Visual Studio 
2. Press F5 to build and run 
3. Enter your name when prompted 
4. Ask about: password, phishing, scam, privacy, malware, safe browsing 
 
## Features 
- WinForms GUI with black and cyan theme 
- Voice greeting on startup 
- Keyword recognition for 8 cybersecurity topics 
- Random responses for variety 
- Sentiment detection (worried, curious, frustrated) 
- Memory and recall of user name and favourite topic 
- Conversation flow with follow-up support
